# Web Scraping Excel Automation

A Python project that scrapes book data from Books to Scrape.

## Features
- Extracts book titles
- Collects prices and availability
- Extracts book ratings
- Saves data to Excel
- Records scraping timestamps

## Technologies
- Python
- Requests
- BeautifulSoup
- Pandas
- OpenPyXL

## How to Run

Install dependencies:

pip install -r requirements.txt

Run the scraper:

python scraper.py

Output file: data/products.xlsx
